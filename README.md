# Mac简易课程表

Electron 实现的桌面悬浮「课表小组件」，**以 macOS 版本为主、Windows 版本为辅**：在本机按规则解析教务课表（无需 AI、无需联网），生成结构化课表，并在桌面以「今日 / 明日课程、月历」视图展示，支持上课前系统通知提醒。

> 说明：小组件是 Electron 无边框悬浮窗口**模拟实现**，不是 WidgetKit 原生小组件；重启电脑后需启动本应用，小组件才会出现。

## 一、是否需要 AI / 联网？

**完全不需要。** 不调用任何云端或本地大模型，不装 Ollama，不申请 API Key，课表数据全程留在本机。

解析原理是针对教务系统常见排版写的规则引擎（见 `src/parser.js`、`src/importer.js`）：

| 表格类型 | 示例表头 | 说明 |
| --- | --- | --- |
| 课程清单型（最准） | 校区 / 课程名称 / 周次 / 教室 / 上课时间 / 教师 | 教室与上课时间一一对应，连堂自动合并 |
| 单元格型周课表 | 时间 / 节次 / 星期一 … 星期日 | 按节次作息表换算起止时间 |

节次作息默认按「每节 45 分钟、小节间休息 10 分钟、大课间 20 分钟」配置（1-2 节 08:10-09:50，5-6 节 14:20-16:00，9-10 节 19:30-21:10），可在 `userdata/config.json` 里用 `periodTimes` 覆盖。

## 二、打包成可直接运行的软件

已内置 `electron-builder` 配置，可打包成 macOS `.app` 与 `.dmg`（仅 arm64 / Apple Silicon）。

```bash
cd mac课程表
npm install          # 安装 Electron + electron-builder

npm run pack         # 仅生成可运行 .app（快，用于自测）→ dist/mac-arm64/Mac简易课程表.app
npm run dist         # 生成 .dmg 安装包与 .zip → dist/
```

打包产物：

```
dist/
├── mac-arm64/Mac简易课程表.app      # 可直接拖到「应用程序」
├── Mac简易课程表-1.0.0-arm64.dmg    # 拖拽安装
└── Mac简易课程表-1.0.0-arm64.zip
```

### 未签名的打开方式（个人自用）

没有 Apple 开发者账号时打出来的是**未签名**安装包，首次打开会被 Gatekeeper 拦截：

- 首次打开：右键 App 图标 →「打开」→ 弹窗中再点「打开」；
- 或：系统设置 → 隐私与安全性 → 下滑到「仍要打开」；
- 如提示文件已损坏：`xattr -cr "/Applications/Mac简易课程表.app"`。

若要对外分发且不被拦截，需要 Apple Developer 账号（¥688/年）做开发者签名 + 公证（notarize），个人自用无需办理。

### 打包后的数据位置

- 开发模式（`npm start`）：项目目录 `userdata/config.json`、`userdata/courses.json`
- 打包后的 App：`~/Library/Application Support/mac-simple-course-widget/`（应用显示名为「Mac简易课程表」）

两种情况数据都只存在本机。

## 三、运行与使用

开发模式：

```bash
npm install
npm start
```

使用流程：

1. 打开应用，在「基础设置」中：
   - 选择**开学第一周的周一**（用于计算教学周）
   - 设置课前提醒开关与提前分钟数（5 ~ 30）
   - 主题模式可选「跟随系统 / 始终浅色 / 始终深色」，主窗口与小组件同步生效
   - 可选「自定义背景」：导入自己的图片作为小组件背景（图片复制到应用数据目录）；打开「主窗口也使用该背景」后可同时作为主窗口背景
2. 在「课表导入」中二选一：
   - **网址导入（推荐）**：填写教务课表网址 → 点「用内置浏览器打开并登录」→ 在弹出的浏览器窗口里自己登录并进入课表页面 → 回到主窗口点「抓取当前页面并解析」；课表页面免登录时可直接点「直接抓取并解析」
   - **表格 / 源码导入**：在教务页面框选课表内容复制粘贴（表格文本即可），或粘贴网页源码 → 点「开始解析」
3. 在「课程管理」中核对结果：可在「列表编辑」和「周课表」两种视图间切换（周课表按周一 ~ 周日 × 上课时段展示，点击某节课直接编辑），点击「保存课表」，桌面小组件自动同步更新。
4. 系统托盘图标：打开主配置窗口、显示 / 隐藏小组件、切换显示模式、查看明天课程 / 回到今天、退出应用。
5. 小组件上右键：切换显示模式、查看明天 / 回到今天、刷新课表数据、关闭小组件；顶部 ‹ › 箭头可直接切换今天 / 明天 / 后天；拖拽可移动位置，右下角手柄可缩放尺寸（内容会随大小自适应）。

## 四、目录结构

```
mac课程表/
├── main.js                  # 主进程：窗口、托盘、通知、导入解析、业务计算
├── preload-main.js          # 主窗口预加载（受控 API）
├── preload-widget.js        # 小组件预加载（受控 API）
├── package.json             # 含 electron-builder 打包配置
├── src/
│   ├── store.js             # config.json / courses.json 读写与容错
│   ├── schedule.js          # 教学周计算、课程过滤、字段校验
│   ├── importer.js          # 导入预处理（网页源码 / 表格文本）+ 单元格型周课表解析
│   ├── parser.js            # 课程清单型表格解析 + 节次作息表
│   └── lunar.js             # 农历展示（仅展示，不参与课程计算）
├── renderer/
│   ├── index.html           # 主设置 / 导入 / 课程编辑窗口
│   ├── widget.html          # 桌面小组件页面
│   ├── css/main.css
│   ├── css/widget.css
│   ├── js/main-render.js
│   └── js/widget-render.js
├── assets/                  # 托盘图标与应用图标
└── userdata/                # 开发模式下的本地数据
```

## 五、已知限制

- 规则引擎只覆盖常见教务排版（课程清单表、单元格型周课表）；遇到特殊排版的课表可能解析不出，需人工在「课程管理」中补录或修正。
- 无自动登录爬虫：需要登录的教务系统请用「网址导入」的内置浏览器自己登录后抓取；也可手动粘贴课表表格内容导入。
- 不使用任何 AI：不携带、不下载、不调用任何大模型；节次时间按内置作息表换算，学校作息不同需自行校正。
- 小组件在部分 Electron 版本下无法真正固定到 macOS 桌面图层，会退化为普通窗口层级并常驻所有桌面空间。
- 农历仅用于展示，不参与任何课程时间计算。
